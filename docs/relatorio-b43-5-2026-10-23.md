### 4.1 Constantes de W1 e a emulação usada

Calculei as constantes com uma emulação independente em Python, sem copiá-las da saída Java. A
emulação foi conferida antes contra as constantes do B-43.7b: `sementeToken(42) =
2621948109880469469`, `DECISOES_40` e a âncora `mix64(0x9E3779B97F4A7C15) = 0xE220A8397B1DCDAF`.

```python
M64 = (1 << 64) - 1
def s64(x): x &= M64; return x - (1 << 64) if x >> 63 else x
def mix64(z):                                   # finalizador SplitMix64
    z &= M64
    z = ((z ^ (z >> 30)) * 0xBF58476D1CE4E5B9) & M64
    z = ((z ^ (z >> 27)) * 0x94D049BB133111EB) & M64
    return s64(z ^ (z >> 31))
class JRandom:                                  # java.util.Random (LCG de 48 bits)
    MUL, MASK = 0x5DEECE66D, (1 << 48) - 1
    def __init__(s, seed): s.seed = (seed ^ s.MUL) & s.MASK
    def next(s, bits):
        s.seed = (s.seed * s.MUL + 0xB) & s.MASK
        r = s.seed >> (48 - bits)
        return r - (1 << 32) if bits == 32 and r >> 31 else r
    def nextInt(s, bound):                      # bound = 100 (nao potencia de 2)
        r = s.next(31); m = bound - 1; u = r
        while True:
            r = u % bound
            if u - r + m < (1 << 31): return r
            u = s.next(31)
SAL_MISTURA = int.from_bytes(b"MISTURAS", "big")   # 0x4D49535455524153
sementeMistura = lambda s: mix64(s ^ SAL_MISTURA)
```

## 8. O que é e o que não é reprodutível

**É reprodutível.** Com o mesmo jar, a mesma `--seed`, o mesmo `--rep` e o mesmo `--threads`, cada
*thread* produz a mesma sequência de intenções, como prefixo de uma sequência infinita fixa. Isso vale
para:

- os tipos de operação (`randomDaMistura`);
- as chaves Zipf e, logo, os *slots* da v3 (`KeyGenerator`);
- as decisões de *token* antigo (`MisturaV3.Cliente`, DT-008);
- o rodízio de identidades de Login (`IdentidadesMistura`).

Os três geradores ficam em domínios separados. O `KeyGenerator` usa a própria `sementeThread`; o
*token* usa `mix64(s ^ SAL_TOKEN)`; a mistura usa `mix64(s ^ SAL_MISTURA)`.

A evidência está em dois níveis:

- **Unidade:** W3, W6, W7 e W8 provam isso no `rodarCliente` real, com chamadas iguais em dois mundos
  novos.
- **Cluster:** o *smoke* mostra 179 159 eventos iguais entre P1 e P2, com 1 *thread*.

**Não é reprodutível:**

- a intercalação entre *threads* (escalonamento e latência);
- as latências;
